# Project instructions

Before broad repository exploration, read `docs/project-map.md` first. It is the compact orientation map for entry points, config files, main modules, and features, and should reduce repeated raw source scans.

Before making changes, read and follow these files completely:

- `app/development/project-guidelines/project-guidelines.md`
- `.cursor/rules/project-structure.mdc`

Treat both as required repository instructions. If they conflict:
1. Follow the user's explicit request.
2. Follow `AGENTS.md`.
3. Follow `project-structure.mdc`.
4. Follow `project-guidelines.md`.

When adding or moving files, verify that the resulting layout complies with the structure guidelines.
